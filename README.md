### Things I've built

- **CodeInsight** *(Final Year Project)* — a bottom-up pipeline that generates documentation for whole codebases at file, folder, and project level using LLaMA-family models, with chunking for large files and hierarchical grounding to reduce hallucination. Evaluated with BERTScore and an LLM-as-judge setup.
- **Chat with your Codebase Docs** — a RAG system that turns those hierarchical docs into a queryable knowledge layer you can ask in natural language.
- **[good-boi-agent](https://github.com/AliyanAhmed29/good-boi-agent)** — an AI grooming **sales agent** that constrains an LLM (Llama 3.3 70B via Groq) to a structured 7-step sales funnel implemented as a finite state machine. Extracts lead info into Pydantic models, drives dynamic service recommendations from the database, and ships with an admin CRM dashboard. Built with a layered, swappable architecture (Streamlit · SQLAlchemy 2.0 · Pydantic v2).
- **[catchAndScore](https://github.com/AliyanAhmed29/catchAndScore-assemblyLanguage)** — a two-level arcade game written from scratch in 8088 assembly, rendered straight to VGA text-mode memory.
